fontgate — sample reports

Two reports produced by the CLI from a real baseline run: Microsoft YaHei Regular (19.7 MB TTC) subset to WOFF2 against a three-file demo site. Paths were rewritten to relative form; every number is measured.

Coverage audit → 361 code points × 1 face. Six characters in the sample text have no glyph in the font; each is listed with its code point, occurrence count and source line. Subset verification → 19.7 MB → 104.7 KiB (0.544%). Seven checks: format, tables, identity, coverage, metrics, layout, budget.

Reproduce locally:

python demo/run_demo.py
